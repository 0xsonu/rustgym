# Frequency Counter

## Concept

Combining HashSet and BTreeMap lets you solve complex problems. Use HashSet for uniqueness and BTreeMap for sorted output.

## Task

Implement `char_frequency(text: &str) -> Vec<(char, usize)>` that returns character frequencies sorted by frequency (descending), then alphabetically.

## Requirements

- Count each character's frequency (skip whitespace)
- Sort by frequency descending
- For equal frequencies, sort alphabetically
- Return as Vec of (char, count) tuples
