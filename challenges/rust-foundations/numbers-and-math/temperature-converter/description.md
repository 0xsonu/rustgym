# Temperature Converter

## Concept

Arithmetic with floating-point numbers is common in real-world programs. The formulas for temperature conversion are:

- Celsius to Fahrenheit: `F = C × 9/5 + 32`
- Fahrenheit to Celsius: `C = (F - 32) × 5/9`

## Task

Implement two functions:

1. `celsius_to_fahrenheit(celsius: f64) -> f64`
2. `fahrenheit_to_celsius(fahrenheit: f64) -> f64`

## Requirements

- Use the standard conversion formulas
- Return `f64` values
