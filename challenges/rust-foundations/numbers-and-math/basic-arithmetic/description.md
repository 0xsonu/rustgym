# Basic Arithmetic

## Concept

Rust supports standard arithmetic operators: `+`, `-`, `*`, `/`, and `%` (remainder).

```rust
let sum = 5 + 3;       // 8
let difference = 10 - 4; // 6
let product = 3 * 7;    // 21
let quotient = 20 / 4;  // 5
let remainder = 17 % 5;  // 2
```

## Task

Implement the function `calculate(a: i32, b: i32)` that returns a tuple with the sum, difference, product, quotient, and remainder of `a` and `b`.

## Requirements

- Return `(a + b, a - b, a * b, a / b, a % b)` as a tuple of `i32` values
- Assume `b` is never zero
