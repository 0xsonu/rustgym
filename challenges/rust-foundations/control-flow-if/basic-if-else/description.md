# Basic If/Else

## Concept

In Rust, `if` is an expression that can return a value. The basic syntax uses `if`, `else if`, and `else`.

```rust
let status = if score >= 90 { "A" } else { "B" };
```

## Task

Implement `sign(n: i32) -> &'static str` that returns `"positive"`, `"negative"`, or `"zero"` based on the value of n.

## Requirements

- Return `"positive"` for n > 0
- Return `"negative"` for n < 0
- Return `"zero"` for n == 0
