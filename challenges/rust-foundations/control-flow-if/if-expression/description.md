# If Expression

## Concept

Since `if` is an expression in Rust, you can use it on the right side of a `let` statement to assign values conditionally.

```rust
let label = if count == 1 { "item" } else { "items" };
```

## Task

Implement `absolute_value(n: i32) -> i32` that returns the absolute value of n using an if expression.

## Requirements

- Use `if` as an expression (assign the result to a variable)
- Return the absolute value without using `.abs()`
