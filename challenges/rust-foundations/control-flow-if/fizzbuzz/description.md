# FizzBuzz

## Concept

Combining multiple conditions with `if/else if/else` lets you handle complex branching logic. Order matters — the first matching condition wins.

## Task

Implement `fizzbuzz(n: u32) -> String` that returns:

- `"FizzBuzz"` if n is divisible by both 3 and 5
- `"Fizz"` if n is divisible by 3
- `"Buzz"` if n is divisible by 5
- The number as a string otherwise

## Requirements

- Check divisibility by 15 first (both 3 and 5)
- Return a `String` in all cases
