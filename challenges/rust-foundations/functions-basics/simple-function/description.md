# Simple Function

## Concept

In Rust, you define functions with the `fn` keyword. Functions can return values using the `->` syntax. The last expression in a function body is implicitly returned.

```rust
fn greet() -> String {
    String::from("Hello!")
}
```

## Task

Implement the function `add(a: i32, b: i32) -> i32` that returns the sum of two integers.

## Requirements

- Define a function that takes two `i32` parameters
- Return their sum
