# Hello Variables

## Concept

In Rust, you create variables using the `let` keyword. By default, variables are **immutable** — once you assign a value, you cannot change it.

```rust
let name = "Rust";
let year = 2015;
```

## Task

Implement the function `create_greeting()` that returns the string `"Hello, Rust!"`.

## Requirements

- Use a `let` binding to create a variable holding the greeting
- Return the greeting as a `String`
