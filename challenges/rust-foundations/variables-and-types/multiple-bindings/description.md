# Multiple Bindings

## Concept

You can destructure tuples and use multiple `let` bindings to work with several values at once:

```rust
let (x, y) = (10, 20);
let name = "Alice";
let age = 30;
```

## Task

Implement the function `personal_info()` that returns a tuple containing a name, age, and whether the person is a student.

## Requirements

- Return a tuple `(String, u32, bool)`
- Name should be `"Alice"`
- Age should be `30`
- Student status should be `true`
