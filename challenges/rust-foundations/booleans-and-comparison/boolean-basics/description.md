# Boolean Basics

## Concept

The `bool` type in Rust has two values: `true` and `false`. Booleans are the result of comparison operations:

```rust
let is_greater = 5 > 3;  // true
let is_equal = 4 == 4;   // true
let is_less = 2 < 1;     // false
```

## Task

Implement the function `check_age(age: u32)` that returns `true` if the person is 18 or older, and `false` otherwise.

## Requirements

- Return a `bool` value
- Age 18 and above should return `true`
- Age below 18 should return `false`
